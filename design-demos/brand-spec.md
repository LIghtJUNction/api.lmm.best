# LMM Forge Design Direction Spec

## Product Truth

- Product: LMM Forge
- Public role: open-source bounty collaboration and delivery tracking
- Real capabilities represented in the concepts: publish funded work, accept a challenge, submit Issue or pull request evidence, review delivery, settle escrowed rewards, tip, rate, and dispute
- Pre-activation workspace: Challenges, Wallet, Profile, and a restrained Developer access action
- Prototype data is representative and must be labelled as a preview; it is not live production data

## Identity

- Working wordmark: `LMM Forge` set as text; no official standalone logo asset exists yet
- Wordmark asset status: honest text treatment for direction review, final mark pending approval
- Public tagline: `Open-source bounty collaboration and delivery tracking.`
- Tone: editorial, practical, accountable, contributor-focused

## Visual System

- Near black: `#141413`
- Ivory: `#FAF9F5`
- Soft ivory: `#F0EEE6`
- Direction A accent: cactus `#BCD1CA`
- Direction B accent: clay `#D97757`
- Direction C accent: heather `#CBCADB`
- Display face: Lora Variable, already installed in the production frontend
- Interface face: Public Sans Variable, already installed in the production frontend
- Illustration grammar: a full-frame opaque accent field, one irregular ivory carrier, and thick near-black gestural marks with deliberate asymmetry
- No gradients, shadows, glossy effects, photographic stock art, or generic purple SaaS styling

## Asset Status

- The three bundled Anthropic-style images are reference-only and must not ship in LMM Forge.
- Original bitmap generation is pending because the built-in image generator is unavailable in the current session.
- Direction prototypes use CSS/HTML editorial motifs only. Production requires an original project-bound bitmap before the selected direction is complete.

## UI Constraints

- Cards use at most 8px radius and are reserved for repeated challenge items or framed tools.
- Page sections remain unframed bands; no cards inside cards.
- Buttons use familiar icons when the production component library provides them.
- Body copy is at least 14px with 4.5:1 contrast.
- Fixed-format progress and action controls keep stable dimensions across viewport sizes.
- Public and contributor surfaces must not display provider, model, relay, gateway, or protocol terminology.

## Legal And Attribution

- AGPL, NOTICE, upstream attribution, and required license links remain intact.
- Public payment copy must describe actual account credits and transaction effects accurately.
